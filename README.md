# Vijay & Navya — Wedding Invitation Website

Simple, single-page wedding invitation for **Vijay Maddineni & Navya Bharathi Bikki**,
Wednesday, December 23, 2026, Dallas, Texas.

- Temple theme in mustard yellow, maroon and cream, matching the invitation video
- English / Telugu toggle
- Live countdown to the wedding (Dec 23, 2026, 10:21 AM CST)
- Events: Pellikuthuru, Pellikoduku, Mehandi, Haldi, Vratam
- RSVP form for the wedding + 4 events, sent via WhatsApp

## View it

GitHub Pages: https://vijaymaddineni17.github.io/Vijay-Navya-Wedding/

## Edit

Edit `index.html` — everything (styles, text, countdown, RSVP) lives in that one file.
To change the venue, search for "Dallas, Texas" and replace it.
To change where RSVPs go, update the WhatsApp number in the form script.
